# iPhone Management Practice

A small C++ console exercise organized into model, repository, service, and view headers. It displays an in-memory iPhone list, while lookup, deletion, and parts of the add-menu input remain unfinished.

From the repository root, compile with `g++ -std=c++17 -x c++ main.c++ -o iphone-manager.exe`, then run `./iphone-manager.exe`; a C++ compiler is required.
